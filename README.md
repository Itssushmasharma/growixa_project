# Growixa

AI-powered marketing automation and customer engagement platform.

Growixa MVP is a **single-tenant, multi-user** web application that lets one company's
internal marketing team manage contacts, run email campaigns, schedule social posts, and
use an AI content assistant with human approval — all from one dashboard.

Status: **documentation phase**. No product code exists yet. See [`docs/DOCUMENTATION_VALIDATION_REPORT.md`](docs/DOCUMENTATION_VALIDATION_REPORT.md)
