# Growixa

Growixa is an AI-powered growth and marketing automation platform. It begins with email
and social media automation, then expands into SEO, AEO, GEO, website intelligence,
content optimization, and integrated growth workflows.

Growixa's **MVP** is a **single-tenant, multi-user** web application that lets one
company's internal marketing team manage contacts, run email campaigns, schedule social
posts, and use an AI content assistant with human approval — all from one dashboard. SEO,
AEO, GEO, and website-intelligence capabilities are part of the long-term product but are
deferred to later releases (V1.5+) — see [`docs/01-product/ROADMAP.md`](docs/01-product/ROADMAP.md).

Status: **documentation phase**. No product code exists yet. See [`docs/DOCUMENTATION_VALIDATION_REPORT.md`](docs/DOCUMENTATION_VALIDATION_REPORT.md)
for current readiness once available, and [`docs/00-project-control/PROJECT_STATUS.md`](docs/00-project-control/PROJECT_STATUS.md)
for the live status.

## Scope note

The MVP does **not** include SEO automation, website crawling, AEO/GEO optimization,
WordPress/GitHub integration, or Search Console integration — those are deferred to future
releases, not cancelled. The original discovery document for that side of the product is
preserved at [`docs/archive/source-prd-seo-aeo-geo-website-intelligence/`](docs/archive/source-prd-seo-aeo-geo-website-intelligence/README.md)
and mapped into future scope at [`docs/01-product/FUTURE_SCOPE_SEO_AEO_GEO.md`](docs/01-product/FUTURE_SCOPE_SEO_AEO_GEO.md).
