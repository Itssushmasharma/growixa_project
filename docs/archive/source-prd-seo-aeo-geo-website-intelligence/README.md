# Source PRD — SEO / AEO / GEO / Website Intelligence

- Status: SOURCE MATERIAL (not authoritative for current scope)
- Related documents: [FUTURE_SCOPE_SEO_AEO_GEO](../../01-product/FUTURE_SCOPE_SEO_AEO_GEO.md), [DECISIONS §DEC-GRX-001](../../00-project-control/DECISIONS.md), [ROADMAP](../../01-product/ROADMAP.md)

This is **not** a description of a different or cancelled product. It is the original
discovery document for Growixa's SEO / AEO / GEO / website-intelligence capabilities —
the "growth" half of "AI-powered growth and marketing automation platform."

Growixa's MVP scope was narrowed to email marketing, social automation, contact
management, AI content assistance, campaign scheduling, and basic analytics
(see [DEC-GRX-001](../../00-project-control/DECISIONS.md)). The capabilities described in
`prd/FULL_PRD.md` — technical SEO, on-page SEO, AEO, GEO, website crawling, WordPress
integration, GitHub integration, Search Console integration, competitive intelligence,
authority/outreach, and AI-visibility monitoring — remain part of Growixa's long-term
product vision and are staged into future releases (V1.5–V3). See
[`FUTURE_SCOPE_SEO_AEO_GEO.md`](../../01-product/FUTURE_SCOPE_SEO_AEO_GEO.md) for the
requirement-to-release mapping.

Do not delete this document. Do not implement any capability from it until the email/social
MVP is stable and the corresponding future release is scheduled.
